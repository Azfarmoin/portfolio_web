# Azfar Moin | Portfolio

React + Vite + GSAP + React Three Fiber. Run with `npm install && npm run dev`.

## Updating content

Everything you edit lives in **`src/data/content.js`**:

- `experience`: add a block for each role, internship or simulation.
- `certificates`: add a block per certificate. For an image, put the file in `public/certificates/` and set `image: "/certificates/name.jpg"`.
- `skills`: add a tool to a category's `items` list, or add a new category.
- `projects`: title, description, stack, `github` and optional `live` URL.

Save the file and the page updates.
